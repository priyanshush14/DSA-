##  My Approach

I'm following a simple approach:

1. Understand the problem.
2. Try to solve it myself.
3. Write the solution.
4. Test and debug it.
5. Push the solution to this repository.
6. Move on to the next problem.

I'm intentionally keeping this repository as a record of my **actual learning and problem-solving journey**.

Some solutions may be optimized, while others may simply represent the best approach I could come up with at the time.
